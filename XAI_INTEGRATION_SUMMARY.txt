1. Get API Key:
   → Visit: https://x.ai/api
   → Sign up / log in
   → Create API key (starts with "xai-")

2. Add to .env:
   cd apps/backend
   echo "XAI_API_KEY=xai-your-key-here" >> .env

3. Restart Backend:
   npm run dev

4. Test:

   → Search for content

📊 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Flow:
1. User searches Internet Archive content
2. Backend calls xAI Grok API with content
3. Grok analyzes for historical accuracy
4. Returns truth score (0-100) + summary
5. If API fails → Falls back to mock (no errors!)

Example Response:
{
  "score": 95,
  "summary": "NASA Apollo 11 mission, verified historical event",
  "verified": true,
  "sources": ["NASA Archives", "Historical Records"]
}
