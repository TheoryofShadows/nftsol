var(--radius-xs)       →  4px    (Micro-elements)
var(--radius-sm)       →  8px    (Badges, small elements)
var(--radius-md)       →  16px   ⭐ BASE (Most elements)
var(--radius-lg)       →  24px   (Modals, overlays)
var(--radius-xl)       →  32px   (Large containers)
var(--radius-full)     →  ∞      (Pills, circles)

USAGE:
  <div style={{ borderRadius: 'var(--radius-md)' }}>Content</div>

────────────────────────────────────────────────────────────────────────────

.rounded-xl           32px        Large containers, major sections

  <button style={{ borderRadius: '16px' }}>Bad</button>

✅ RIGHT: Using CSS variables
  <button className="rounded-md">Good</button>
  <button style={{ borderRadius: 'var(--radius-md)' }}>Good</button>

❌ WRONG: Mixing inconsistent radii
  <button className="rounded-xl">Bad (too rounded on mobile)</button>

  <button className="btn-rounded">Good</button>

❌ WRONG: Forgetting mobile testing

💡 TIPS & TRICKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TIP 1: Use .rounded-app as your default
  Most elements should use className="rounded-app" (16px)

TIP 2: Combine with shadows for depth
  <div className="rounded-app shadow-soft hover:shadow-soft-lg">

TIP 3: Smaller elements = smaller radii
  Icons: .rounded-icon (8px)
  Badges: .rounded-badge (full)

TIP 4: Larger containers = larger radii
  Modals: .rounded-modal (24px)
  Sections: .rounded-lg (24px)

TIP 5: Test on mobile
  Always verify your design scales properly on mobile devices

TIP 6: Reference the quick guide
  Save ROUNDED_DESIGN_QUICK_REFERENCE.md for quick lookup

TIP 7: Use semantic names
  Instead of memorizing sizes, use .card-rounded, .btn-rounded, etc.

TIP 8: Override with CSS variables
  Need custom radius? Create new media query and override --radius-md
