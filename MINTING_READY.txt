🚀 START MINTING IN 10 MINUTES:

1️⃣  PREREQUISITES (5 minutes)
   • Install Solana CLI: https://docs.solana.com/cli/install-solana-cli-tools
   • Create wallet: solana-keygen new --outfile ~/.config/solana/devnet.json
   • Get address: solana address -k ~/.config/solana/devnet.json
   • Get SOL: solana airdrop 2 YOUR_ADDRESS --url devnet
   • Upload image: https://nft.storage (free)
   • Copy IPFS URL from nft.storage

2️⃣  START BACKEND (1 minute)
   Terminal 1:
   $ cd NFTSol
   $ npm run dev
   
   Wait for: ✅ Server running on http://localhost:3001

3️⃣  MINT YOUR NFT (2 minutes)
   Terminal 2:
   $ node mint-nft-quick.js
   
   Answer prompts:
   • Wallet address: (your devnet wallet)
   • NFT name: "My First NFT"
   • Symbol: (optional)
   • Description: (optional)
   • Image URL: (your IPFS URL)

4️⃣  VIEW YOUR NFT (1 minute)
   You'll get a mint address. View it:
   https://explorer.solana.com/address/MINT_ADDRESS?cluster=devnet

✨ DONE! You have your first NFT! 🎊
