═══════════════════════════════════════════════════════════
🎯 WHAT EACH VARIABLE DOES
═══════════════════════════════════════════════════════════

VITE_API_BASE
  → Tells your frontend where your backend API is hosted
  → Must match your Render backend URL
  → Example: https://nftsol-xyz123.onrender.com

VITE_SOLANA_RPC_URL
  → Solana blockchain RPC endpoint for frontend
  → Uses Helius enhanced RPC for better performance
  → Includes your API key in the URL

VITE_SOLANA_CLUSTER
  → Which Solana network to use
  → mainnet-beta = production
  → devnet = testing

VITE_HELIUS_API_KEY
  → Your Helius API key (separate from RPC URL)
  → Used by Helius service for DAS API calls
  → Same key as in your RPC URL

VITE_IMG_PROXY_BASE
  → Backend URL for proxying IPFS images
  → Usually same as VITE_API_BASE
  → Helps with CORS and performance

VITE_GA_TRACKING_ID
  → Google Analytics tracking ID
  → Format: G-XXXXXXXXXX
  → Optional - for analytics tracking

═══════════════════════════════════════════════════════════
⚠️ IMPORTANT NOTES
═══════════════════════════════════════════════════════════

✓ All VITE_* variables are exposed to the frontend
✓ Never put backend secrets in VITE_* variables
✓ Your Helius API key is safe to expose (it's rate-limited)
✓ The backend URL must be HTTPS in production
✓ After adding variables, redeploy for changes to take effect

═══════════════════════════════════════════════════════════
🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

If frontend can't connect to backend:
  → Check VITE_API_BASE matches your Render URL
  → Ensure backend CORS includes your Netlify URL
  → Verify backend is deployed and running

If wallet connection fails:
  → Check VITE_SOLANA_RPC_URL is correct
  → Verify Helius API key is valid
  → Test RPC URL in browser

If images don't load:
  → Check VITE_IMG_PROXY_BASE is set
  → Verify backend image proxy endpoint works
  → Check IPFS gateway is accessible

═══════════════════════════════════════════════════════════
✅ VERIFICATION CHECKLIST
═══════════════════════════════════════════════════════════

Before deploying, make sure:

□ VITE_API_BASE points to your Render backend URL
□ VITE_SOLANA_RPC_URL includes your Helius API key
□ VITE_SOLANA_CLUSTER is "mainnet-beta" for production
□ VITE_HELIUS_API_KEY matches the key in RPC URL
□ All variable names start with VITE_ (required by Vite)
□ No trailing slashes in URLs
□ URLs use HTTPS (not HTTP)
□ After adding variables, trigger new deploy
