1. Deploy Anchor program:
   cd apps/smart-contracts/solana_rewards
   anchor build && anchor deploy --program-name eternal_echoes

2. Update program ID in 3 files (see QUICK_START.md)

3. Run database migration:
   cd apps/backend
   npx drizzle-kit push:pg

4. Start backend:
   npm run dev

5. Start frontend:
   cd apps/frontend
   npm run dev

6. Test at: http://localhost:5173
   → Click "🎬 Eternal Echoes" tab
