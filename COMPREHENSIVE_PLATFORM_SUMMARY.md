## 🏗️ Complete Architecture

### Frontend Layer (Netlify)
```
React 18.3 + TypeScript 5.9 + Vite 7.1
├── UI Framework: Tailwind CSS 3.4 (Glassmorphism design)
├── State Management: React Query (TanStack)
├── Blockchain: Solana Wallet Adapter (9 wallets)
├── Performance: Lazy loading, code splitting, caching
├── User Experience: Onboarding tours, animations, confetti
└── Analytics: Google Analytics integration
```

### Backend Layer (Render)
```
Node.js 20 + Express 4 + TypeScript 5.9
├── Database: PostgreSQL + Drizzle ORM
├── Auth: JWT + Session management + Redis
├── Security: Helmet, CORS, rate limiting, input validation
├── Logging: Winston + Morgan + Audit trails
├── Blockchain: Solana Web3.js + Metaplex + Anchor
└── External APIs: Helius, Pinata, Irys, OpenAI
```

### Blockchain Layer
```
Solana Mainnet + Devnet
├── SPL Token: CLOUT (26iJ37BE3icVtoo2QRkfjtYXFHMudG2sbTHAnhF2D6ab)
├── Compressed NFTs: Metaplex Bubblegum 5.0.2
├── Smart Contracts: CLOUT, Market, Loyalty programs
├── RPC: Helius enhanced endpoints
└── Storage: Arweave (Irys) + IPFS (Pinata)
```
